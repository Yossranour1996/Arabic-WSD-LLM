# Arabic Word Sense Disambiguation with Generative LLMs

This repository contains the code, data preprocessing scripts, and fine-tuning configurations for the paper:

> **Zero-Shot and Fine-Tuned Evaluation of Generative LLMs for Arabic Word Sense Disambiguation**

## 📂 Contents
- `data/` – Scripts to format Dataset A and Dataset B for experiments
- `scripts/` – Training and evaluation scripts
- `results/` – Model outputs and evaluation metrics
